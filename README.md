# jen_center_of_excellence
Oct2026JenDay - Runbooks, context, playbooks, and sundry for setup and use of systems for CauseMic work.

## Contents

- `runbooks/`: step-by-step setup and recovery guides
  - [causemic-ascendably-git-separation.md](runbooks/causemic-ascendably-git-separation.md): keeping CauseMic and Ascendably Git, GitHub, and Claude accounts separate on one Mac
  - [causemic-github-ssh-setup.md](runbooks/causemic-github-ssh-setup.md): step-by-step, Claude-guided setup for any CauseMic team member (Mac, Windows or Linux) (SSH key in 1Password, clone CauseMic-Hub repos)
- `knowledge/`: reusable CauseMic know-how (Salesforce, HubSpot, products, security, project management), mostly captured from Slack before its 90-day limit. See [knowledge/README.md](knowledge/README.md)
- `skills/capture-slack-knowledge/`: the skill that scans work Slack channels and drafts `knowledge/` entries

No secrets (keys, passwords, tokens) or client data go in this repo.

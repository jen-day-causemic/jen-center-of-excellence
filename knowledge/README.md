# CauseMic knowledge

Reusable know-how from CauseMic conversations: tips, decisions, product news, security notices and delivery practice. Most of it starts in Slack, which only keeps 90 days of history, so it's captured here with the `capture-slack-knowledge` skill.

Written to be shared firm-wide later. Client names may appear as pointers to examples; client data never does.

## Folders

| Folder | For |
|---|---|
| `salesforce/` | Core Salesforce platform |
| `salesforce-nonprofit/` | Nonprofit-specific Salesforce (NPSP, Nonprofit Cloud and successors) |
| `hubspot/` | Core HubSpot platform |
| `hubspot-nonprofit/` | Nonprofit-specific HubSpot |
| `products/` | One file per third-party product, with which CRMs it works with |
| `security/` | Vulnerabilities, access practice, data handling |
| `project-management/` | How CauseMic runs projects: hours tracking, project notes, status reporting, scoping, client comms, lessons learned |

Folders appear once they have an entry.
